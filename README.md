# 药品分辨器

帮助视障用户识别药品、听取信息、找到药品并管理服药计划。

本仓库保存经过脱敏的源码快照，属于开发原型。

## 功能

- 语音引导拍照、药名朗读和药箱格子定位。
- 服药日历、过期提醒、语音操作和高对比界面。
- VoiceOver适配，以及多种OCR方案探索。
- Flutter、Expo、uni-app及HTML演示等不同实现。

## 运行

使用 HBuilderX 打开本目录，选择运行到浏览器或真机。OCR、语音与视觉识别配置在 `services`；公开版不包含凭证。部署时应使用后端代理保存服务密钥。本仓库收录 uni-app 主原型，其他技术版本尚未合并。

## 当前范围

已有多个原型和离线演示版本。

- 不同版本的能力需要分别确认。
- 离线演示使用本地药品选择，不能视为真实药盒识别。
- OCR准确性、NFC及原生通知仍需真机验证。

## 验证

Vue 页面与 JavaScript 通过语法检查；未进行原生打包、真机 OCR、NFC 或服务调用验证。
